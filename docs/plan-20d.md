## 6. GitLab 操作步骤（今天必做）

1. 安装 Git for Windows（当前机器没有 `git`）：<https://git-scm.com/download/win>；
2. 浏览器登录 <https://course.educg.net>，进入 GitLab，新建项目 `proj54-SynRun`；
3. 项目成员里邀请刘宇豪（Developer 及以上）；可见性按赛方要求（一般 Public）；
4. 本地初始化并推送：

```bash
cd rcore-memlab
git init -b main
git add .
git commit -m "stage1: 确定知识点 Sv39 地址翻译，整理 rCore 源码对照"
git remote add origin https://course.educg.net/<你的组>/proj54-SynRun.git
git push -u origin main
```

5. 按四阶段补提交（每次提交能编译）：

| # | 提交信息 | 内容 |
| --- | --- | --- |
| 1 | `stage1: 确定知识点与原理梳理` | README、知识点说明 |
| 2 | `stage1: rCore 源码对照表` | 设计文档对照章节 |
| 3 | `stage2: 帧分配器与 FrameTracker` | frame.rs |
| 4 | `stage2: Sv39 页表 map/unmap/translate` | paging.rs |
| 5 | `stage2: 命令层与实验脚本` | kernel/repl/ui |
| 6 | `stage3: 配套测试样例与 --check` | cases、tests |
| 7 | `stage3: 使用说明与实验指导书` | docs |
| 8 | `stage3: 新增边界用例` | cases 补充 |
| 9 | `stage4: 幻灯片、视频与提交材料` | submission/ |

6. 推送后在网页确认：文件齐全、commit 列表 ≥ 8、README 能正常显示；
7. 可选：同时 mirror 到 GitHub，答辩时展示更稳。
